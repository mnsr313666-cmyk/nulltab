# NullTap — شروع پروژه

این ZIP یک اسکلت اولیه Next.js برای وب‌سایت NullTap و اتصال رابط TON Connect است؛ پروژه هنوز محصول کامل یا آماده انتقال توکن روی شبکه اصلی نیست.

## نیازمندی‌ها
- حساب GitHub
- حساب Render
- Node.js 20 یا بالاتر (برای اجرای محلی؛ برای انتشار می‌توان از Build/Start روی Render استفاده کرد)

## انتشار از طریق GitHub و Render
1. فایل ZIP را از حالت فشرده خارج کن.
2. در GitHub یک repository جدید با نام `nulltap` بساز.
3. فایل‌های داخل پوشه را در repository آپلود کن (خود ZIP را به‌عنوان کد آپلود نکن).
4. در Render گزینه New + و سپس Web Service را انتخاب کن و repository را وصل کن.
5. تنظیمات:
   - Runtime: Node
   - Build Command: `npm install && npm run build`
   - Start Command: `npm start`
6. پس از انتشار، Render یک آدرس HTTPS می‌دهد.
7. در `app/providers.tsx` و `public/tonconnect-manifest.json` مقدار `YOUR-APP-DOMAIN.onrender.com` را با دامنه واقعی خودت جایگزین کن، commit/push کن و منتظر انتشار مجدد بمان.
8. در Render باید Node version سازگار (ترجیحاً 20 یا 22) انتخاب شود، اگر تنظیم آن در محیط در دسترس است.

## مهم
- این نسخه فعلاً فقط رابط اولیه و دکمه اتصال کیف پول را دارد.
- قبل از استفاده واقعی، دامنه در manifest باید دقیق و عمومی باشد و فایل manifest از HTTPS باز شود.
- آدرس Jetton Master و اعشار NULL باید از منبع معتبر زنجیره تأیید شوند. آدرس کیف پول دریافت‌کننده کارمزد با آدرس Jetton Master یکی نیست.
- منطق انتقال واقعی توکن، محاسبه 99% گیرنده و 1% کارمزد، بررسی موجودی و نتیجه تراکنش، بک‌اند بازی و دیتابیس هنوز پیاده‌سازی نشده‌اند.
- انتقال Jetton در دو پیام لزوماً اتمیک نیست؛ برای اعمال مطمئن کارمزد باید طراحی تراکنش و قرارداد/روتر به‌درستی بررسی و تست شود.
- هرگز عبارت بازیابی یا کلید خصوصی Tonkeeper را در سایت، فایل env یا چت وارد نکن.
